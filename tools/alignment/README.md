# أداة المحاذاة — المرحلة الثانية

هذه الأداة غير مفعلة في الـMVP. المسار المقترح للفصول المرخصة القصيرة:

1. تقسيم المادة إلى ملف مستقل لكل فصل.
2. `faster-whisper` بنموذج `small` و`compute_type=int8_float16` على GTX 1650 4GB.
3. WhisperX للمحاذاة الدقيقة عند توفر نموذج عربي مناسب.
4. إخراج JSON يطابق `Sentence[]` و`TokenTiming[]` في واجهة API.
5. مراجعة بشرية قبل النشر.

لا تضع ملفات صوت أو نصوص محمية بحقوق نشر داخل المستودع.

## صوت الـMVP

يستخدم `tools/tts_edge.py` نفس إعدادات مولد سطح المكتب: صوت
`ar-SA-HamedNeural` من Edge TTS، بسرعة `+0%` ونبرة `+0Hz`. يعيد كذلك توقيت
الكلمات لربط التلوين بالصوت الفعلي بدل المؤقت التقديري.
