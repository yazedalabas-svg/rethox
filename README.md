# rethox

MVP عربي RTL للكتب الرقمية والسرد التفاعلي. يحتوي على كتالوج وبحث وسلة وشراء تجريبي ومصادقة وصلاحيات وقارئ متزامن وTTS وتلخيص محفوظ ولوحة إدارة.

## التشغيل

```powershell
cd C:\Users\yazed\rethox
npm install
npm run dev
```

- الواجهة:
- API: http://127.0.0.1:4181/api/health

حساب الإدارة التجريبي:

- `admin@rethox.local`
- `Rethox2026!`

## الفحص

```powershell
npm test
npm run build
```

## ملاحظات

- الدفع وهمي ولا يسحب أموالًا.
- بيانات الكتب والمستخدم التجريبي خيالية.
- لا تُستخدم ملفات ري زيرو أو أي محتوى غير مرخص.
- وضع JSON الحالي مخصص للتجربة المحلية؛ استخدم مخطط Prisma وPostgreSQL قبل النشر الحقيقي.
# نشر التحديثات من الكمبيوتر

انقر مرتين على `Update-Rethox.cmd`. الأداة تفحص البناء، تمنع ملفات الأسرار، ثم ترفع التغييرات إلى GitHub. Render ينشر تلقائيًا بعد الرفع.

لإجبار Render على النشر فورًا، انسخ `tools/deploy.local.example.ps1` إلى `tools/deploy.local.ps1` وضع رابط **Deploy Hook** الخاص بالخدمة في المتغير `deployHook`. هذا الملف محلي ومُستثنى من Git.
